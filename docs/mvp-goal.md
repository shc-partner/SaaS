# MVP Goal — Stage 1: Generate & Export

> **본 문서는 현재 단계(Stage 1)의 목표를 고정하기 위한 단일 진실원이다.**
> 다른 모든 문서·결정은 본 문서와 충돌하지 않아야 한다.

## 1. Stage 1의 한 줄 정의

**"고객이 위저드를 통해 기업 소개형 웹사이트를 생성하고, 산출물을 zip/tar로 다운로드해서 자신의 머신에서 실행할 수 있다."**

운영형 SaaS 호스팅은 Stage 2 이후. 지금은 **생성 + 내보내기**가 전부.

## 2. 포함 (In-scope)

- 고객 가입 / 로그인 (최소)
- 단일 사이트 유형: **기업 소개형 (company-intro)**
- 위저드: 회사 정보, 로고, 소개 문구, 연락처, 메뉴 구조 등 입력
- 생성 엔진:
  - React 프런트엔드 코드 생성 (템플릿 + 입력 데이터 주입)
  - plain PHP 백엔드 코드 생성 (관리자 + 공개 API)
  - MySQL 스키마 + seed 데이터 생성
- 패키징: `.zip` 또는 `.tar` 단일 파일
- 다운로드: 산출물 다운로드 링크 제공 (단기 만료)
- 산출물 자체에 포함되는 것:
  - `README.md` (실행 방법)
  - `docker-compose.yml` (즉시 실행 가능)
  - `.env.example`
  - 빌드 스크립트(`npm install`, `npm run build` 등)

## 3. 제외 (Out-of-scope, 후속 단계)

- 호스팅된 멀티테넌트 런타임 (사이트별 도메인, SSL, 라우팅 자동화)
- 결제·플랜·구독·청구
- 팀·역할·세분화 RBAC (Stage 1은 owner + 본인만)
- 알림 (이메일/카카오/SMS)
- 분석·로그 수집
- **플랫폼 UI** 의 모바일 최적화 (위저드/대시보드/관리자 화면) — 데스크탑 전용으로 고정
  - 산출물(생성된 회사 사이트) 의 frontend 는 반대로 **반응형 필수**. 정책 단일 진실원: [ui-policy.md](ui-policy.md)
- 다른 사이트 유형 (블로그, 예약, 회원, 교육 등 — 모두 Stage 2 이후)
- 다국어
- 템플릿 마켓플레이스
- 산출물 자동 배포 (Netlify, Vercel 등 연동)

## 4. 성공 검증 시나리오

다음 흐름이 처음부터 끝까지 동작해야 Stage 1 성공:

1. 신규 사용자 가입
2. "사이트 생성" 클릭 → 위저드 진입
3. 회사 정보·메뉴·소개 입력 → 생성 요청
4. 시스템이 생성 작업 수행 (수 초 ~ 수십 초)
5. 다운로드 링크 노출 → `company-{slug}-{timestamp}.zip` 다운로드
6. 사용자가 압축 해제 → README 따라 `docker compose up` 1회
7. 브라우저에서 공개 사이트 + 관리자 로그인 동작 확인

위 7단계가 깨지지 않으면 다른 모든 기능은 후순위.

## 5. 비기능 요건 (Stage 1 한정)

- 생성 1건 평균 소요: **30초 이내** (목표, 실측 후 조정)
- 산출물 크기: 빌드 전 기준 **수십 MB 이내** (node_modules 제외, lockfile 포함)
- 동시 생성 작업: MVP는 큐 없이 순차 처리도 허용 (단, 실패 시 재시도 가능)
- 다운로드 링크 만료: **7일 또는 N회 다운로드 후** (정책 결정 대기)

## 6. 결정 원칙 (이 단계의 의사결정 기준)

새 기능·요구가 들어왔을 때 다음 질문 순서로 판단:

1. **"이게 위 4번 시나리오를 가능하게 하거나, 안정시키는가?"** → 예: 진행. 아니오: 보류.
2. **"산출물이 플랫폼 없이 독립 실행되는 데 기여하는가?"** → 예: 진행. 아니오: 보류.
3. **"플랫폼만 좋아지는 기능인가?"** → 가능하면 Stage 2로.

## 8. Stage 1 → Stage 2 졸업 조건 (참고)

본 문서는 **Stage 1만** 다루지만, 다음 항목이 안정되면 Stage 2 논의 시작:
- 위 7단계 시나리오의 실패율 < 1% (수동 생성 100건 기준)
- 산출물이 외부 머신 3종에서 그대로 부팅
- 다운로드·만료·재다운로드 흐름 안정
- 생성기 템플릿 1종(company-intro)이 코드 변경 없이 입력만으로 다양한 회사를 표현 가능
