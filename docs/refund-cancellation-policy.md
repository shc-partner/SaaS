# 환불 및 해지 정책 (초안 / Draft)

> ⚠️ **본 문서는 초안입니다. 실제 적용 전 반드시 변호사 검토를 받아야 합니다.**
> 전자상거래법·약관규제법·소비자기본법·콘텐츠산업진흥법 적용 검토 필수.

본 정책은 [terms-of-service-draft.md](terms-of-service-draft.md), [service-lifecycle-policy.md](service-lifecycle-policy.md) 와 함께 적용된다.

## 1. 무료/유료 플랜 기준

### 1.1 무료 플랜
- 결제·환불 대상 아님
- 해지: 관리자 페이지에서 즉시 가능
- 데이터 처리: 유료와 동일한 grace → terminated 흐름 적용

### 1.2 유료 플랜
- 결제 주기: 월간·연간 (구체 가격은 별도 페이지)
- 자동 갱신을 원칙으로 하되, 갱신 전 해지 가능
- 부가가치세 등 세금 별도 표기

## 2. 해지 절차
1. 관리자 페이지 → 계정 → 해지 신청
2. 해지 사유 입력(선택, 통계용)
3. 본인 확인(이메일/2FA)
4. 해지 확정 시점에 사이트 `status: active → grace` 전환
5. 확인 메일 발송(유예 종료일·export 안내 포함)

> 회사 측 해지(약관 위반·결제 실패 등) 시에도 동일하게 grace로 진입 (긴급 위반은 즉시 suspended 후 grace 처리).

## 3. 환불 기준

### 3.1 자발적 해지 시
- **월간 결제**: 결제일로부터 7일 이내 + 서비스 미실질 사용 시 전액 환불 (전자상거래법 청약철회권)
  - "실질 사용"의 정의: 사이트 생성·콘텐츠 발행·고객 데이터 수신 등 (확정 필요)
- **월간 결제, 7일 경과**: 잔여 일수 일할 환불 또는 환불 불가 (정책 결정 필요)
- **연간 결제**: 미사용 월수 기준 일할 환불, 단 행정비용 또는 할인분 차감 가능

### 3.2 회사 측 사유로 해지 시
- 서비스 장애·중단·정책 변경 등 회사 귀책 시 잔여 기간 전액 환불

### 3.3 약관 위반에 의한 강제 해지 시
- 환불 없음(약관에 명시 + 사전 통지 절차 거친 경우)

> ⚠️ 위 기준은 한국 전자상거래법·콘텐츠 청약철회 규정 검토 후 확정 필요.

## 4. 해지 후 유예 기간 (Grace Period)
- 기본 **30일** (변경 시 약관·이 문서 동시 갱신)
- 유예 기간 중 사이트는 공개 노출 중단(`status=grace`)
- 관리자 페이지는 **읽기 전용 + export** 기능만 활성
- 결제 재개·해지 철회 시 즉시 `active` 복구 가능
- 유예 만료 7일 전·1일 전 알림 메일 발송 권장

## 5. 유예 기간 중 Export 가능 여부
- **유예 기간 동안 export 무제한·무료 제공**
- 다운로드 링크는 생성 후 7일 유효
- export 산출물 범위·형식: [export-and-migration-policy.md](export-and-migration-policy.md)

## 6. 유예 종료 후 운영 데이터 삭제 정책
- 유예 만료 시점에 사이트 `status: grace → terminated`
- 다음을 운영 DB·스토리지에서 삭제:
  - 사이트 콘텐츠(페이지, 블록, 메뉴, 미디어)
  - 사이트 설정·테마·도메인 매핑
  - 예약·문의·사이트 회원 데이터
- 삭제 시각·실행자·대상 site_id를 **개인정보 비포함 감사 로그**로 보존

## 7. 법적 보관 의무가 있는 데이터 예외 처리
다음 데이터는 운영 데이터와 분리된 보존 영역에서 법정 기간 동안 별도 보관 가능 (실제 적용 항목·기간은 법무 검토 필수):

| 항목 | 보존 근거(예시) | 권장 보존 기간 |
|---|---|---|
| 결제·세금계산서 기록 | 전자상거래법, 세법 | 5년 |
| 계약·청약철회 기록 | 전자상거래법 | 5년 |
| 소비자 분쟁·민원 기록 | 전자상거래법 | 3년 |
| 접속 로그(보안) | 통신비밀보호법 | 3개월 |
| 부정 이용·약관 위반 조사 기록 | 회사 정책 + 법령 검토 | 1년 (안) |

- 보관은 **암호화 + 접근 권한 최소화** 원칙
- 보관 항목·기간은 [privacy-policy-draft.md](privacy-policy-draft.md)에 동기화 표기

## 8. 백업 데이터 삭제 원칙
- 백업은 운영 데이터와 별도 보존 주기를 가진다.
- 기본: 운영 데이터 삭제 후 **추가 30일**까지 백업 보존(전체 ≤ 60일 from 해지)
- 만료 시 자동 삭제, 별도 삭제 로그 보존(개인정보 비포함)
- 정보주체의 즉시 삭제(잊혀질 권리) 요청 시:
  - 가능 범위 내 운영 데이터 즉시 삭제
  - 백업 즉시 삭제는 기술·운영상 일정 시간 소요 가능 — 사실 고지 + 기한 내 처리 약속

## 9. 정책 변경
- 본 정책은 변경 시 사전 공지(중대 변경은 30일 이상)
- 변경 전 시점에 시작된 결제·해지 건은 변경 전 정책을 적용

## 10. 분쟁
- 환불·해지 분쟁은 회사 고객 지원 → 한국소비자원 → 관할 법원 순으로 해결을 권장
